每当开始一个新项目，我总会习惯性地列出一长串依赖。直到有一天，试着先问自己：浏览器已经能做什么？

答案比想象中丰富。

## 一个真正的对话框

原生 `dialog` 元素已经处理了许多容易忽略的细节：焦点约束、Escape 关闭，以及处于页面上方的顶层显示。

```javascript
const dialog = document.querySelector('dialog');
dialog.showModal();
// 关闭时，焦点会回到打开它的元素。
```

加上一点样式，它就能成为一个很好用的搜索面板。

## 用变量表达主题

CSS 自定义属性不仅可以保存颜色，也可以表达一套设计的语义。

```css
:root {
  --paper: #f7f8f2;
  --ink: #263328;
}

[data-theme='dark'] {
  --paper: #1b211d;
  --ink: #e8ecdf;
}
```

组件使用的是「纸张」和「墨色」，而不是某个具体色值。换主题时，只需要改变变量。

## 少一层，也是一种选择

这并不意味着所有库都没有价值。而是说，在安装一个新依赖之前，值得花几分钟看看平台本身。

原生能力往往有更长的生命周期，也让我们对网页的运行方式理解得更深一点。
